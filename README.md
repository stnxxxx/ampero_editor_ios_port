# Ampero Editor для iOS

Неофициальный редактор пресетов **Hotone Ampero Mini (MP-50)** для iPhone и iPad.
Работает по USB-MIDI через CoreMIDI — тем же протоколом, что и официальный Ampero Editor для Windows/macOS.

> Hotone не публикует протокол. Он восстановлен сообществом: проект
> [ampero-bridge](https://github.com/dhrandy/ampero-bridge) (MIT) записал трафик официального
> редактора и проверил его на реальной педали с прошивкой **V2.2**. Подробности — в [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Что умеет

- Подключение к педали по USB (USB-C напрямую, Lightning — через Camera Connection Kit).
- Выбор пресета (99 пользовательских, P1-1 … P33-3), чтение пресета с педали.
- Цепочка из 9 блоков (FX1 → FX2 → AMP → NR → CAB → EQ → FX3 → DLY → RVB): вкл/выкл, выбор модели.
- Редактирование параметров: ползунки, переключатели, списки — с именами и диапазонами из официального редактора.
- Сохранение пресета в любую ячейку под новым именем.
- Живое обновление, когда крутите ручки на самой педали.
- Чтение имён всех пресетов, MIDI-монитор с ручной отправкой байт (для исследования протокола).

## Структура

```
AmperoKit/                 Swift-пакет без UI (можно тестировать отдельно)
  Protocol/                SysEx-кадры, разбор 460-байтной записи пресета, события педали
  Transport/               CoreMIDI (UMP / MIDIEventList) и конвертер MIDI 1.0 ↔ UMP
  Device/AmperoMini.swift  actor: очередь записей с паузами, чтение пресетов, сохранение
  Catalog/                 модели и параметры из Resources/*.json
  Tests/                   тесты по реальным захватам с педали
AmperoEditor/              SwiftUI-приложение (iOS 17+)
project.yml                описание проекта для XcodeGen
docs/PROTOCOL.md           протокол на русском
```

## Сборка

Нужен Mac с Xcode 15+ (на Windows iOS-приложение собрать нельзя).

```bash
brew install xcodegen
```

```bash
xcodegen
```

```bash
open AmperoEditor.xcodeproj
```

В Xcode выберите свою команду (Signing & Capabilities), подключите iPhone/iPad и запустите.
Тесты пакета: `swift test` в папке `AmperoKit` (на macOS).

## Сборка и установка без Mac (Windows + iPhone)

1. **Проверка без сборки.** Поставьте из App Store любой MIDI-монитор (например, MIDI Wrench),
   подключите педаль к iPhone и убедитесь, что она появилась в списке устройств. Отправьте
   Program Change — педаль должна переключить пресет, CC 48 = 0/127 — выключить/включить FX1.
2. **Сборка в облаке.** Загрузите папку проекта в репозиторий GitHub. Workflow
   `.github/workflows/build-ios.yml` на маке GitHub прогонит тесты, соберёт приложение и выложит
   `AmperoEditor-unsigned.ipa` во вкладке Actions → нужный запуск → Artifacts.
   В публичных репозиториях macOS-минуты бесплатны; в приватных минуты macOS расходуются в 10 раз быстрее.
3. **Установка.** На Windows поставьте [Sideloadly](https://sideloadly.io) и iTunes (версию с сайта Apple,
   не из Microsoft Store — нужна для драйверов iPhone). Подключите iPhone, перетащите .ipa в Sideloadly,
   войдите своим Apple ID. На iPhone: Настройки → Конфиденциальность и безопасность → Режим разработчика → вкл,
   затем Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
   С бесплатным Apple ID приложение работает 7 дней, потом его надо переподписать (или купить
   Apple Developer за $99/год и ставить через TestFlight).

## Что не проверено и требует проверки на железе

1. **Видит ли iOS педаль.** USB-MIDI интерфейс педали класс-совместимый, но у неё слегка нестандартные
   USB-дескрипторы (на Linux ядро ругается на `maxpacket`). На macOS/iOS это обычно не мешает, но проверить нужно.
   Педаль также потребляет питание — с iPhone может понадобиться отдельное питание педали (9 В).
2. **Сохранение.** Педаль принимает сохранение, только если оба кадра пришли одной USB-передачей.
   Приложение отправляет их одним `MIDIEventList` с одной меткой времени — так CoreMIDI должен склеить
   их в один пакет, но это нужно подтвердить на экране педали.
3. **RVB = слот 09**, выбор моделей на NR и FX3 — на педали ещё не подтверждены.
4. **Delay Time при включённом Sync** — время принимает только 11 шагов (кратно 398); сейчас ползунок
   показывает миллисекунды и не привязан к шагам.
5. Сообщение `00 02 06 04 01 NN` трактуется как «выбран пресет NN» — это гипотеза.

## Безопасность педали

- Записи идут в одну очередь с паузой 0,3 с (ampero-bridge использует 0,5 с), движения ползунка сливаются.
- Значения всегда ограничиваются диапазоном из каталога (например, Classic PS Range ≤ 5 — значение 6 вешает педаль).
- Блоки включаются только через CC — SysEx-кадр `10 06 00 00 00` роняет педаль.
- Перед экспериментами сделайте бэкап пресетов официальным Ampero Editor.

## Дальнейшие шаги

- Бэкап/восстановление всех пресетов в файл (формат записи уже разобран — см. `PatchRecord`).
- Привязка Delay Time к долям при Sync, tap tempo.
- Глобальные настройки, IR-загрузка, драм-машина и лупер — протокол для них ещё не исследован.
  Для исследования удобно использовать MIDI-монитор в приложении и прокси `winmm.dll` из
  [ampero-re](https://github.com/macedo/ampero-re) для записи трафика официального редактора на Windows.
