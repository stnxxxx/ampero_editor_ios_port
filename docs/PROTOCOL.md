# Протокол Hotone Ampero Mini (прошивка V2.2)

Официальной документации по протоколу у Hotone нет. Всё ниже — результат реверс-инжиниринга
проекта [ampero-bridge](https://github.com/dhrandy/ampero-bridge) (MIT): трафик официального
Ampero Editor записан и проверен на реальной педали. Пометка «не доказано» означает, что
это ещё не подтверждено на педали.

## Транспорт

- USB `84ef:0080`, интерфейс 3 — стандартный USB-MIDI 1.0 (bulk OUT `0x03`, bulk IN `0x83`, один кабель).
  Класс-совместимый, поэтому на iOS виден через CoreMIDI без драйверов.
- Педаль **не отвечает** на стандартный Identity Request.
- Педаль **не подтверждает записи**. Проверить можно только перечитав пресет.
- Педаль сама рассылает SysEx при работе с ней: heartbeat `00 02 06 05 …`, счётчик `00 02 06 04 01 NN`,
  изменения параметров `10 AA 00 02 …`.

## SysEx-кадр

```
F0 21 25 7F 4D 50 2D 32 <kind> <body> F7
```

`kind` = `12` (данные) или `11` (запрос). Контрольной суммы нет, тело — 7-битные байты.
**Это не заголовок Ampero II Stage/Stomp** (`21 25 4D 50 00 00 <ck>`), кадры от них не подходят.

## Обычный MIDI (канал 1)

| Сообщение | Действие |
| --- | --- |
| Program Change `C0 nn` | выбрать пресет, 0-based (75 = P26-1). 99 пользовательских пресетов, по 3 в банке |
| CC 48…56, `0`/`127` | вкл/выкл блоков FX1, FX2, AMP, NR, CAB, EQ, FX3, DLY, RVB |
| CC 22 / 23 | банк вниз / вверх |
| CC 24 / 25 | пресет вниз / вверх |
| CC 7 | уровень пресета 0–99 |
| CC 57 / 58 | навигация по экрану (на главный / назад) |

## SysEx-команды

Слот `AA`: `01` FX1, `02` FX2, `03` AMP, `04` NR, `05` CAB, `06` EQ, `07` FX3, `08` DLY, `09` RVB (RVB — вероятно).

| Что | Тело (после `kind 12`) |
| --- | --- |
| Выбор модели | `10 AA 00 01 HH LL` — код модели 14 бит (два 7-битных байта, старший первым). Сбрасывает параметры блока к значениям модели по умолчанию |
| Параметр | `10 AA 00 02 HH LL SS HI LO` — `HH LL` = код модели, **которая сейчас стоит в блоке** (иначе запись молча игнорируется), `SS` = номер параметра, `HI LO` = 14-битное сырое значение |
| Сохранение | кадр A `00 02 06 07 01 <idx>` + кадр B `10 00 00 00 01 <idx> <имя 18 байт, NUL-padding>` — **оба одной USB-передачей**. Сохраняет буфер редактирования |

**Никогда не отправляйте** `10 06 00 00 00` — это маркер состояния, который рассылает сама педаль;
запись его с хоста роняет педаль. Блоки включаются только через CC.
Значение вне диапазона тоже может подвесить педаль (Classic PS Range = 6 → блок заблокирован до перезагрузки).

## Чтение пресета

Читается **всегда выбранный сейчас** пресет (индекс в запросе игнорируется). Чтобы прочитать другой —
сначала Program Change, пауза ~300 мс, затем:

```
11  00 02 0A 00 00 00
12  00 02 13 00 01 <idx> 01
12  00 02 15 00 01 <idx> 00 <n> 01      n = 0..4
11  00 00 05 01
```

Ответ: заголовок `00 02 12 …`, пять чанков `00 02 14 00 01 <idx> 00 <n> <данные>`, трейлер `00 02 16 …`.
Данные разбиты по полубайтам (каждый байт несёт 4 бита). После склейки — запись 460 байт.

## Запись пресета (460 байт)

| Смещение | Поле |
| --- | --- |
| 0 | `01` |
| 1 | индекс пресета |
| 3 | уровень 0–99 |
| 4–21 | имя, 18 байт ASCII |
| 95 + 33·k | блок k (FX1, FX2, AMP, NR, CAB, EQ, FX3, DLY, RVB) |
| 459 | контрольная сумма — педаль пересчитывает сама, не писать |

Блок: `<вкл> <модель hi> <модель lo> <x> <p0 lo> <p0 hi> <p1 lo> <p1 hi> …` (модель = hi·128 + lo).

Исключения (уже учтены в `PatchRecord.swift`):

- **DLY**: Feedback — один байт на +6; Time — 14 бит в +7 (старшие 7) и +8 (младшие 7), `raw + 20 = мс`.
  У 2290 Mod (код 16) Mod Rate — 14 бит в +9/+10. При включённом Sync время — 11 шагов по 398 (1/1 … 1/16).
- **Sweller** (FX1 142, FX2 126, FX3 75): Attack — 14 бит в +3/+4, `raw + 80 = мс`.
- **CAB**: Position Z — байт +12; Low Cut — 14 бит +13/+14 (`0` = Off, иначе `raw + 19` Гц);
  High Cut — +15/+16 (`1801` = Off, иначе `2000 + 10·raw` Гц).
- **EQ Para EQ** (код 4): 15-й параметр Volume — один байт на +32.
- Полосы EQ хранятся как «показанное значение + 50».

## Тайминги (из опыта ampero-bridge)

- ≥ 0,5 с между записями (в приложении по умолчанию 0,3 с + слияние движений слайдера);
- ~3 с тишины до и после сохранения;
- однажды педаль упала на `ParaNum <= GetParaNum(...)` при интенсивной работе — причина не доказана.

## Коды моделей

Коды **не равны** «номер на экране − 1» для всех блоков (FX2: 0–15, 48–54, 80–93, 112–134).
Полные таблицы — в `AmperoKit/Sources/AmperoKit/Resources/model-lists.json` и `param-map.json`
(имена параметров, диапазоны и типы контролов из `algorithm_50.xml` официального Ampero Editor V1.6.0).
